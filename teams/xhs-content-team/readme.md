# 小红书内容执行项目组

用于承接品牌小红书种草、新品发布与系列笔记交付的执行项目组。你可以直接通过「通用总管秘书」给它派活，也可以直接进项目组群聊下达素材与要求。

## 团队分工

- **内容策划**：研读产品资料与卖点，拆解多角度选题与标题钩子。
- **笔记主笔**：结合品牌语气撰写正文、标签与配图建议，响应中途改价等需求变更。
- **质量审校**：核对价格、参数、合规词与图文一致性，汇总最终交付包。

## 底层依赖与准备

- 底层使用成员身份：`OpenCode · Plus 版`（安装时会自动检查并联动安装）。
- 不含任何 API Key；导入桌面端后按提示配置你的模型凭证即可运行。
