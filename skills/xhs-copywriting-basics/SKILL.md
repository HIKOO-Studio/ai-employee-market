# 小红书笔记起草与核对

从用户给出的主题、受众和使用场景出发，完成可供审阅的笔记草稿。

1. 读取用户提供的资料，摘出会影响文案的商品名称、价格、规格、活动日期和适用条件。信息互相冲突时采用用户明确确认的最新版本，其余标成待确认。缺少资料时保留占位符。
2. 每篇选一个受众能认出的具体场景。标题控制在 20 字内。正文从具体需要写起，说明商品细节和使用建议，再用一个自然的问题收尾。附上 3–6 个与场景相关的话题标签。根据资料选择细节；产品使用体验、用户评价、功效和销售数据都需要来源。
3. 交付前逐篇对照价格和规格，尤其检查标题、正文、配图说明中重复出现的信息。用户补充新价格或活动日期时，检查本批草稿中所有引用位置。
4. 逐篇对照品牌禁用词，删去无依据的最高级、保证性措辞和医疗功效承诺。成稿供用户审阅，未获明确授权时禁止对外发布。
5. 直接在对话中交付草稿，在文末集中列出需要用户确认的事实。仅在用户要求时将草稿写入其指定目录。
