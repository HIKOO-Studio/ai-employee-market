# 客户端公共界面与交互规范（DESIGN_SPEC）

## 1. 纸面连续性与零布局抖动（硬性要求）
- 异步到达的系统提示、更新提醒**禁止插入文档流顶部**，严禁通过动态改变 `.workspace` 网格行数把对话区、侧栏或输入框往下顶（禁止出现启动闪跳 / Layout Shift）。
- 异步提醒必须使用**书页内轻浮层（浮动纸签 / Toast）**，采用 `position: fixed` 或相对工作区的 `position: absolute` 悬浮在右上角（避开右侧书签栏与底部输入区）。

## 2. 视觉层次（禁止双层套盒）
- 浮层必须使用**单层纸签容器**：直接使用 `background: var(--paper-raised)`、`border: 1px solid var(--line-gold)` 和轻阴影 `box-shadow: var(--shadow-soft)`。
- **禁止**在有背景色的外层矩形容器中再嵌套一层带边框圆角的 `.notice-box`（双层套盒在 600px 窄窗下显得臃肿且占高度）。

## 3. 交互与按钮约束
- **不得擅自改动既有工具栏按钮顺序**（当前既有顺序见 `app-config.json`）。
- 提醒卡片只提供与当前状态直接相关的操作（正常态：「前往市场查看」「关闭」；查看失败态：保留原信息并提供「重试」「关闭」），不得堆砌无关入口。
- 多次触发查新或重复渲染时，容器内按钮必须保持唯一，不得重复追加 DOM 节点。
