# 小红书笔记起草与核对

适合已有商品简报、活动说明或价格表的小红书运营人员。提供资料后可以要求起草笔记，或用最新价格表复核一批已有草稿。交付包括标题、正文、话题标签和待确认事实。

在 Claude Code 项目内，将本包的 `SKILL.md` 放在 `.claude/skills/xhs-copywriting-basics/SKILL.md`，在项目中调用 `/xhs-copywriting-basics`。所有写作步骤都包含在这一份文件中。

本 Skill 读取用户指定的写作资料，默认在对话中给出草稿。按要求保存草稿时，文件访问仍受客户端权限控制。[Claude Code 技能目录](https://code.claude.com/docs/en/skills)
